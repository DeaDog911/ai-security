## Структура (11 слайдов, ≤ 10 мин)
1. **Титул.** «ПР2. Исследование устойчивости глубокой модели к шуму и естественным искажениям», команда, гр. 1379.
2. **Постановка и baseline.** Corruption robustness (не состязательная); модель и веса не меняются, без переобучения;
   test без служебных сумм; шум — к исходным столбцам до препроцессора. Плашки: M(0) = RMSLE [CI] (BCa),
   MdAPE [CI], доля в ±25% [CI] (Уилсон). Направление: RMSLE меньше — лучше. Источник — `baseline.csv`.
3. **Модель шума.** Таблица 4 типов: код, модальность, искажение, смысл s, связь с ПР1, фактическая доля изменённых
   при s = 0,5. Сетка s ∈ {0; 0,1; …; 0,5} — общая для всех типов; r = 5 реализаций; seed. Источник — `noise_grid.csv`.
4. **Метрики и статистика.** Формулы ΔM, R_rel, R-AUC с направлением; схема парного bootstrap (объект × реализация →
   средняя ошибка объекта → общие индексы для clean и всех точек → кривая и R-AUC на каждой перевыборке);
   критерии: статистическая — CI ΔM без 0; практическая — |ΔM| ≥ 0,02 (разброс между seed обучения ≈ 0,01).
   Проверки: s = 0 через путь шума даёт baseline бит-в-бит.
5. **Robustness Curves.** `curves_rmsle.png` (надзаголовок обрезан, подпись своя). Справа — 3 факта: T1 круче всех;
   X1 ≈ X2; на естественном уровне ПР1 (≈ 23–24%) RMSLE T1 / T2.
6. **Качество по уровням.** Матрица s × тип: M(s) [CI] и ΔM [CI]; разброс между реализациями (max std).
   Источник — `curves.csv`.
7. **R-AUC.** Таблица: тип | R-AUC [CI] | R-AUC_rel [CI] | M(0,5) | ΔM(0,5) [CI] | значимо с s | |ΔM| ≥ 0,02 с s | место.
   Источник — `rauc.csv`, `summary.csv`.
8. **Подгруппы.** Нативная таблица ΔM при s = 0,4 [CI] и R_rel по типу разрешения и наличию площади × 4 типа.
   Источник — `by_group.csv`.
9. **Вклад признаков.** `by_feature.png` (T1 и T2, s = 0,3, портится одна группа) + 3 факта. Источник — `by_feature.csv`.
10. **Смещение прогноза.** Левая панель `bias_curves.png` (средний остаток по s) + таблица по квартилям стоимости при s = 0,5
    (остаток baseline и ΔM по типам) + обрезанные описания. Мысль: «улучшения» под шумом — компенсация смещения.
    Источник — `bias.csv`.
11. **Выводы и ограничения.** Слева — выводы (критичные типы и уровни, уязвимые подгруппы, практические меры, значение для
    ПР3–ПР4), справа — ограничения (из ноутбука). Без чисел.
