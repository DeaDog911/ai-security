(2) Выигрыш C96 тает со временем (по кварталам −0,05…−0,07 в начале val → −0,01…−0,03 в 2024–2026): словарь из train стареет — доля UNK 0,56% (2022) → 1,36% (2026), средняя длина 32 → 40 слов.
