# Прогресс

## Текущее состояние
- Этап: **ПР1 выполнена** (2026-10-31). Следующая — ПР2 (план ещё не составлен и не утверждён).
- Датасет: два набора LADBS 2010–2019 и 2020–н. в., три типа Bldg, 709 309 строк для обучения; split по дате: train 496 596 (… 2022-07-15), val 106 421 (… 2024-09-04), test 106 292 (… 2026-10-24).
- Baseline **зафиксирован** (MSE): FT-Transformer 1,48 млн параметров; test RMSLE 1,031 [1,024; 1,040] (BCa), MdAPE 48,3% [47,9; 48,7], доля в ±25% 0,282 [0,280; 0,285]. Веса — `artifacts/baseline_model.pt`. Обучение бит-воспроизводимо при `set_seed` до создания модели (проверено 2026-10-31); разброс между разными seed ≈ 0,01 RMSLE.
- ПР1: `src/pr1_data_quality.py` → `reports/pr1/` (CSV + PNG, итог `summary.csv`/`summary.md`), ноутбук `notebooks/pr1_data_quality.ipynb` выполнен. Полный прогон на кешах ≈ 22 мин (самое долгое — C2ST по группам признаков ≈ 11 мин); с нуля + OOF 5-fold ≈ 15 мин и MinHash ≈ 2 мин.
- Главные результаты ПР1:
  - полнота: 23,7% пропущенных ячеек, пропуски структурные (Alter/Repair без площади; SUBMITTED_DATE не заполняется у Express Permit);
  - валидность: 14,0% строк с нарушением; VALUATION ≤ 0 6,6%; площадь ≤ 0 у 16,3% заполненных;
  - уникальность: дубли без ID 0,06%, близкие дубли 0,38%; 10,7% — дополнительные разрешения (у 45,5% из них $501);
  - leakage: копий входа в train у 0,02% test; участок test есть в train у 42,9%;
  - метки: label error rate 2,86% [2,82; 2,91] (OOF); $501 — 7,7% меток и 24% подозрительных; 61% оценок кратны $1 000; разбор 20 худших — 16 проблем метки (служебные $501/$1, стоимость проекта на административных разрешениях), 4 ошибки модели;
  - сдвиг: MMD²_u 0,022 (p ≤ 0,001; контроль ≈ 0), C2ST AUC 0,89 (логрег) / 0,92 (MLP) без времени; причины — текстовые шаблоны (Eplan 0,9% → 18,5%), новые census tract (13,7% test), переименованные CNC (23,4% test);
  - аномалии: IsolationForest 1,84% в test против 1% в train; на них ошибка модели ниже (шаблонные тексты).

- **Эксперимент «представление текста»** (2026-10-31, только val, baseline не менялся): `src/experiments/text_tokens.py` → `reports/experiments/text_tokens/` (`summary.md`, `results.csv`, `paired_vs_A.csv`, `by_group.csv`). По 3 seed:
  - A (SVD(64), baseline): val RMSLE 0,985 (0,982–0,988); при seed 42 совпадает с baseline 0,98162;
  - B (SVD(256) → 8 токенов): ΔRMSLE −0,010 (−0,003…−0,016), правило не проходит; MdAPE −1,7 п.п., доля в ±25% +1,9 п.п.;
  - C (слова как токены, L = 72): ΔRMSLE −0,036 (−0,046…−0,018), CI без 0 при всех seed — **формально проходит** правило; выигрыш на Alter/Repair (−0,054) и Apartment (−0,116), на Bldg-New хуже (+0,020); MdAPE не улучшается; в 6 раз медленнее (≈ 125 с/эпоху), 4,3 млн параметров.
  - Оговорки: эпоха выбирается по тому же val, кривые шумные (у C разброс между seed 0,03 против 0,007 у A); на val обрезано 23,7% текстов (на train 3,8%).
  - **Решение о замене baseline за пользователем** (см. «Открытые вопросы»). D (SVD(128)) не запускался.
