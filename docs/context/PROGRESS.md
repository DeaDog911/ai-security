# Прогресс

## Текущее состояние
- Этап: подготовка. Изучены методичка, вводная презентация и датасет; план ПР1 согласован (см. PLAN_PR1.md).
- Готово: `README.md`, `requirements.txt`, `.gitignore`, `scripts/setup_env.ps1` (создание venv через virtualenv + ROCm/CPU PyTorch), `src/config.py`, `src/check_device.py`.
- Не проверено на машине пользователя (в облаке PyTorch не устанавливали по просьбе пользователя; check_device проверен только на синтаксис).

## Следующие шаги
1. Пользователь запускает `scripts/setup_env.ps1` и присылает вывод `check_device.py`; по результату решаем, GPU или CPU.
2. Реализовать остаток этапа 0 (stats, data, features, model, train_baseline).
3. Реализовать ПР1 (скрипт + ноутбук).
