## Варианты (для каждого seed 42, 43, 44)
- **A — эталон.** Текущая модель (SVD(64) → 1 токен). Sanity check: при seed 42 val RMSLE должна совпасть с baseline (0,98162).
- **B — несколько SVD-токенов.** SVD(256) по той же TF-IDF-матрице, разбитый на 8 токенов по 32 компоненты, у каждого своя линейная проекция в d_token. TF-IDF-векторизаторы взять из `artifacts/preprocessor.joblib` (`prep.tfidf_word`, `prep.tfidf_char`), заново обучить только `TruncatedSVD(256, random_state=42)` на train; стандартизация по train. Закешировать матрицу в `artifacts/experiments/text_tokens/`.
- **C — слова как токены.** Словарь из train: нормализованный текст (`features.normalize_text`), простая токенизация по словам и числам, слова с документной частотой ≥ 5, не больше 20 000; PAD = 0, UNK = 1. Последовательность обрезается до L слов. L выбери по распределению длины на train (примерно 95-й перцентиль, но не больше 96) и запиши, сколько текстов обрезано. Каждое слово — обучаемый эмбеддинг + позиционный эмбеддинг; эти токены добавляются в ту же последовательность, что и токены признаков. Существующий SVD-токен оставить. PAD маскировать в attention (`attn_mask` в `scaled_dot_product_attention`). Прочие гиперпараметры — как у baseline (`DEFAULT_HP`, `TRAIN_HP`).
- (Необязательно, если останется время) **D** — SVD(128), один токен.

## Метрики и сравнение (всё на val)
- Для каждого запуска: val RMSLE, MdAPE, доля прогнозов в пределах ±25%, лучшая эпоха, число эпох, секунд на эпоху, число параметров.
- Парный bootstrap против A **с тем же seed**: ΔRMSLE, ΔMdAPE, Δ(доли в ±25%) через `stats.paired_bootstrap_ci` (n ≈ 106 тыс. → percentile).
- Для каждого варианта — среднее и разброс (min–max) по трём seed.
- Разбивка RMSLE по `PERMIT_TYPE` и `PERMIT_SUB_TYPE` для лучшего варианта и A при seed 42: ожидаем выигрыш в первую очередь у Alter/Repair и Commercial.
- **Правило решения:** улучшение считается содержательным, если средний ΔRMSLE по seed ≤ −0,02 и CI парного bootstrap не содержит 0 при каждом seed. Меньшие разницы — в пределах разброса между seed.
